制作実績 ／ 業務自動化ツール

Excel・CSVの「まとめる・整える・突き合わせる」を
ボタン操作だけで

毎月の手作業になりがちな、複数ファイルの結合、列の並べ替えや書式の統一、 2つの表の照合（差分チェック）を自動化する Windows アプリを制作しました。 プログラミングの知識がない担当者でも、画面の操作だけで、毎回同じ品質の結果を出せます。

  • Windows用・インストール不要
  • 元ファイルを書き換えない
  • 処理結果レポートを自動保存
  • 自動テスト 219件 合格
Before / After を見る ご相談について

こんなお困りごとを解決します

Excel や CSV を使う事務作業で、時間がかかる・ミスが起きやすい作業を自動化します。

店舗別・月別に届くファイルを、毎月コピー＆貼り付けで1つにまとめている

ファイルを選んで1クリックで結合。列の並び順や文字コードが違うファイルも自動でそろえます。

CSVをExcelで開くと「00123」が「123」になり、取引先コードが壊れる

コードや番号は文字として扱い、先頭の0を消しません。消えてしまった0を桁数指定で戻すこともできます。

日付の書き方がバラバラ（2024/1/5、2024年1月5日、令和6年1月5日…）

指定した列の日付を1つの書き方に統一。変換できない値は、何行目かを付けて一覧にします。

システムから出したデータを、別システムの取り込み形式に毎回手作業で整えている

列名・順番・書式の設定をファイルに保存。次回からは設定を読み込んで実行するだけです。

注文と出荷、請求と入金などの突き合わせを、目視やVLOOKUPで行っている

「一致・不一致・片方にしかない」を自動で分類。違うセルは赤く色付けしてExcelに出力します。

同じ番号が2行あって、突き合わせの結果がおかしくなったことがある

番号の重複や空欄を事前に見つけ、既定では処理を止めて行番号をお知らせします。

3つの機能

画面上部のタブで機能を切り替えます。どの機能も、実行前に結果をプレビューで確認できます。

機能 ①

一括結合 ― 複数ファイルを1つに

  • CSV・Excel を何個でもまとめて結合（Excelの複数シートにも対応）
  • 文字コード（UTF-8／Shift_JIS）の違いを自動で判別し、文字化けを防止
  • 列の順番が違っても、列名を見て正しくそろえる
  • 「どのファイルから来た行か」が分かる列を追加
  • 読み込めないファイルがあっても止まらず、レポートに記録
機能 ②

列の変換 ― 取り込み形式に整える

  • 列名の変更、並べ替え、不要な列の削除
  • 「1,234」「¥1,000」「▲500」「全角数字」を数値に変換
  • 西暦・和暦・Excelの日付を、指定した書き方に統一
  • 番号の桁数をそろえる（「123」→「000123」）
  • 設定を保存しておけば、次回からワンクリック
機能 ③

照合・差分チェック ― 2つの表を突き合わせる

  • 注文番号＋商品コードのような、複数列の組み合わせで突き合わせ
  • 左右で列名が違っても対応（例: 「注文番号」と「受注No」）
  • 金額は「1円の差までは一致」のような許容範囲を指定可能
  • 番号の重複・空欄を事前にチェックし、誤った突き合わせを防止
  • 結果はExcelに出力。違うセルは赤く表示

こんな業務に応用できます

お使いのファイルの形式に合わせて設定・調整することで、次のような業務に対応できます。

売売上・実績の集約

店舗別・担当者別・月別に届く売上ファイルを、集計前に1つにまとめる。

取システム間のデータ移行

基幹システムや販売管理ソフトの出力を、会計ソフト等の取り込み形式に変換する。

出注文と出荷の突き合わせ

未出荷・数量違い・注文のない出荷を洗い出す。

請請求と入金の消し込み確認

請求データと入金データを照合し、未入金や金額違いを一覧にする。

名名簿・会員リストの更新確認

新旧の名簿を比べ、住所・電話番号の変更、退会・新規の人を抽出する。

品商品マスタの変更点チェック

価格改定や商品名の変更、廃番・新商品を、取り込み前に確認する。

カスタマイズできること

業務に合わせた調整を前提に作っています。ご依頼内容に応じて、次のような対応が可能です。

列の設定
お使いのファイルに合わせた列名・並び順・書式の設定をご用意。以後は設定を読み込むだけで同じ処理ができます。
照合の条件
突き合わせに使う番号、比べる項目、金額の許容範囲、空白や全角・半角の違いを無視するかどうか。
独自の加工
税込金額の計算、社内コードへの置き換え、特定条件の行の除外など、業務固有の処理の追加。
出力の形式
CSV（UTF-8／Shift_JIS）・Excel。決まったレイアウトのExcelへの出力にも対応可能です。
画面
使う機能だけに絞る、項目名を社内の呼び方に合わせる、など。
自動実行
画面を使わずに毎朝決まった時刻に実行する形（Windowsのタスクスケジューラ利用）。

品質への取り組み

業務データを扱うツールとして、「元のデータを壊さない」「間違いを黙って通さない」ことを重視しています。

データを守るしくみ

  • 元のファイルは上書きしない（同じ名前で保存しようとすると止める）
  • 保存中に失敗しても、壊れたファイルを残さない
  • Excelで開いたままのファイルに保存しようとした場合は、閉じるよう案内
  • 処理ごとに、件数・警告・設定内容をレポートに自動保存

テストで確認している内容（一部）

  • 文字コードの違い、先頭0の保持、日付・数値の書き方の違い
  • 番号の重複・空欄、許容範囲ぎりぎりの金額などの境界ケース
  • 日本語のフォルダ名・ファイル名、長いパス
  • 出力したExcelを実際のExcelで開いて表示を確認

制約と未検証事項

ご依頼前に確認いただきたい点です。必要に応じて、ご依頼内容に合わせて対応・検証します。

現在の制約

  • 古い形式の Excel（.xls）とパスワード付きのExcelは読み込めません（.xlsx で保存し直せば利用可能）
  • 結合するファイルは、見出し（列名）の行の位置がそろっている必要があります
  • 画面上のプレビューは先頭200行まで（保存されるファイルには全行が入ります）
  • 照合の許容範囲は「差が○円以内」の形式のみ（「○%以内」は未対応）
  • 集計（日別・月別の合計など）の機能は含まれていません
  • アプリに電子署名がないため、初回起動時に Windows の確認画面が出る場合があります

未検証の事項

  • Windows 10 での動作（Windows 11 で確認済み）
  • 画面の表示倍率 125%・150% での見え方（100% で確認済み）
  • Python が入っていない別のパソコンでの起動
  • 数十万行を超える大きなデータでの処理時間
  • マクロ（VBA）を含む Excel ファイル（.xlsm）
